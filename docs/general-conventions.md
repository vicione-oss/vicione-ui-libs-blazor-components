# General Conventions

This document contains rules that apply to everything written in this
repository: code, comments, documentation and commit messages. The
scope-specific style documents build on it.

## Spelling

Use American English everywhere — identifiers, test names, comments, XML docs,
README and ADR files, and commit messages.

For example:

| Use         | Instead of   |
|-------------|--------------|
| normalize   | normalise    |
| finalize    | finalise     |
| behavior    | behaviour    |
| neighbor    | neighbour    |
| color       | colour       |
| canceled    | cancelled    |
| cancelable  | cancellable  |
| synchronize | synchronise  |
